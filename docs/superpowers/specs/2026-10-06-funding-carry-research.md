# 새 전략 연구: 횡단면 펀딩 캐리 롱숏 (2026-10-06)

> 상태: **실거래 편입 (2026-10-06, 평가금액의 50%)** — 기본 전략 + 숏 스퀴즈 방어(`strategies/carry.py`, `LIVE_OPTIONS`).
> 실거래 구조는 `docs/superpowers/specs/2026-09-29-momentum-live-trading-design.md`의 "펀딩 캐리 50% 편입".
> 아래 1부는 첫 연구(토론 워크플로우), 2부는 개선 연구와 모멘텀 결합.
> 재현: `uv run python -m alpha.backtest.funding_carry [--holdout]` (`src/alpha/backtest/funding_carry.py`)

## 진행 방식

에이전트 13개, 6단계: 제안(캐리·펀딩 / 역추세·변동성 / 수급·구조 전문가 각 2개) → 비판(통계 감사관, 리스크·실행 관리자) →
재반론(수정·반박·철회) → 사회자가 최대 3개 선정·스펙 고정 → 스펙 그대로 백테스트 → 최종 감사(반박 입장에서 재실행).
기존 추세추종의 변형은 제외했다. 제안 단계에서는 성과 계산을 금지했다(데이터를 보고 고르는 과최적화 방지).

### 사전 등록 규칙
- 비용: 편도 0.05% + 실제 펀딩. t 종가로 정한 비중은 t+1부터 보유.
- 개발 기간: 데이터 시작 ~ 2025-09-30. **보류 기간 2025-10-01 ~ 2026-09-28**은 개발 판정을 모두 통과한 뒤 한 번만 계산.
- 합격 기준: ① 개발 Sharpe ≥ 0.7 ② 보류 Sharpe > 0 ③ 파라미터 이웃 모두 > 0.3 ④ 수수료 2배 ≥ 0.5
  ⑤ 상장 폐지 포함 코호트(vision, 2020년 말 이전 상장 80개, 2021-01 ~ 2025-09) > 0.3 ⑥ 실거래 모멘텀과 일 수익률 상관 < 0.5
  ⑦ 2,000 USDT·하루 1회 시장가로 실행 가능, 총 노출 ≤ 1.5배.
- 사회자 추가 조건: 실거래 모멘텀·시장·대조 팩터 회귀 절편 > 0, 수량 고정(비중 표류) 손익 Sharpe ≥ 0.5,
  이벤트형은 독립 이벤트 ≥ 40, 결과를 보고 파라미터·부호·규칙 수정 금지.

### 제안과 결과

| 제안 | 결과 |
|---|---|
| 횡단면 펀딩 캐리 롱숏 | **선정 → 전 기준 통과** (펀딩 쏠림 역행 제안을 흡수) |
| 테이커 매수 쏠림 잔차 역발상 롱숏 | 선정 → 기각. 비용 전 손익부터 음수 (개발 Sharpe -0.32, 이웃 8개 모두 0.3 미만, 코호트 -0.63) |
| BTC 미결제약정 급감 반등 (대칭 이벤트형) | 선정 → 기각. 독립 이벤트 29개 < 40, 성과 계산 전에 중단 (성과 증거가 아니라 표본 부족) |
| 펀딩 급락 후 역발상 매수 | 철회. 트리거일의 68%가 2022년 — 사실상 약세장 롱 한 번에 거는 베팅 |
| 펀딩 쏠림 역행 횡단면 | 철회. 캐리와 같은 가설이라 따로 돌리면 다중 검정 |
| 투매 충격 반전 | 탈락. 위기 유동성 계열은 OI 플러시 하나만 등록, 롱 전용이라 모멘텀과 꼬리 위험이 겹침 |

## 전략 규칙 (확정 스펙)

- 대상: `momentum.UNIVERSE` 56개 (상장 60일 이상, 그날 거래량 > 0, 펀딩 기록이 이어진 코인). 적격 15개 미만이면 무포지션.
- 신호: 일요일 봉 마감 시각 T(월요일 00:00 UTC) 기준, [T − 7일, T) 안 펀딩비 합 (T 정산은 제외, `funding_time.floor('min')`).
- 펀딩 상위 20%(최소 3개, 경계 동률 포함) **숏**, 하위 20% **롱**.
- 비중: 다리 안에서 60일 변동성 역수 비례, 롱 +0.5 / 숏 -0.5 (달러 중립, 총 노출 1.0), 종목당 |비중| ≤ 0.15 (넘는 몫은 현금).
- 리밸런싱: 주 1회 (일요일 종가 = 월요일 00:00 UTC). 보유 중 상장 폐지되면 마지막 유효 종가에 청산.
- 파라미터 이웃: 룩백 4/11일, 분위 10/30%, 리밸런싱 4/10일.

### 최종 감사 (반박 입장에서 재실행)
- **버그·미래 참조 없음**: t 이후 데이터를 지우고 다시 계산해도 비중 차이 0, 신호 창 독립 계산 불일치 0/40.
- **버틴 점검**: 체결 4~12시간 지연 1.48 ~ 1.62, 기여 상위 5개 코인(THETA·BNB·SOL·TRX·AVAX) 제외 1.35,
  저변동성·규모·BTC 팩터를 더한 확장 회귀 절편 연 33.8% (t 4.48, 2022년 이후 17.9%, t 2.60), Deflated Sharpe ≈ 0.99.
- **반박 쪽 증거 (기대치를 낮추는 이유)**:
  - 수익이 앞쪽에 몰렸다. 2020 ~ 2021 Sharpe 2.72 → 2022 ~ 2025-09 1.16, 2022 ~ 2023은 0.49.
  - 수익의 2/3가 펀딩 수취가 아니라 "펀딩 낮은 코인이 가격도 더 오른" 가격 효과이고 생존 편향이 있다:
    2020 코호트에서 UNIVERSE가 아닌 24개(대부분 폐지)만 쓰면 2022년 이후 0.11,
    거래대금 상위 60 동적 목록은 2022년 이후 0.47 (가격 다리 연 +5.5%).
  - 믿을 만한 수익원은 펀딩 다리 (모든 코호트·기간에서 연 +8.6 ~ +17.9%).
- **결론: 실거래 기대 Sharpe 0.5 ~ 1.0, 연 8 ~ 15%**로 잡는다. 실거래 모멘텀과 상관이 거의 0이라 분산 효과가 있다.

### 다중 검정 기록
6개 아이디어 중 3개 시험. 성과 백테스트 약 39회 (캐리 13 + 진단 7, 테이커 19, OI 0 · 이벤트 개수 세기 10).
판정에 쓴 조합 16 ~ 25개. 캐리의 t 4.15와 DSR ≈ 0.99는 이 시도 수로 설명되지 않는다.

## 남은 결정 (실거래로 가려면)

1. **자본**: 별도 서브 계정에 새 자금을 넣을지, 기존 2,000 USDT를 나눌지. 나누면 종목당 금액이 줄어 최소 주문
   (BTC 100 USDT, ETH 20 USDT 등)을 다시 점검해야 한다.
2. **중단 규칙 사전 등록**: 예) 실거래 6개월 Sharpe < 0 또는 MDD < -20%면 중단, 펀딩 다리 누적이 음수가 되면 재검토.
3. 실행 시각은 월요일 00:00 UTC 직후 (하루 지연이면 Sharpe 1.43으로 하락).
4. 파라미터·유니버스·부호는 바꾸지 않는다. 동적 유니버스 등 변형은 새 사전 등록으로 따로 시험.
5. (선택) 실거래 모멘텀과 결합한 포트폴리오 백테스트로 배분 비율 결정.

# 2부: 개선 연구와 실거래 편입 (2026-10-06)

## 코인 목록별 기본 전략 — 생존 편향 점검

| 목록 | 2021-01 ~ 2025-09 | 2022-01 ~ 2025-09 | 보류 2025-10 ~ |
|---|---|---|---|
| U1 고정 56개 (현재 상장) | 1.70 | 1.16 | 1.33 |
| U2 2020년 말 이전 상장 80개 (폐지 20개 포함) | 1.92 | 1.35 | 2.38 |
| U3 시점별 거래대금 상위 60 (679개, 폐지·신규 포함) | 0.92 | 0.47 | **-0.40** |

- U3 보류 기간: 펀딩 +77%/년을 받았지만 가격 -89%/년 (롱 다리 = 음수 펀딩 신규 상장 코인의 폭락, 약 200개 코인에 고르게 퍼짐 — 데이터 오류 아님).
- 고정 56개는 모두 2020년 말 이전 상장이다. 즉 "2020년 말 이전 상장 + 현재 거래 중" 규칙을 앞으로 적용하는 것과 같고,
  그 규칙을 폐지 코인까지 넣어 과거에 적용한 U2가 U1보다 좋다. U1·U3 차이는 생존이 아니라 구성(기성 코인 대 신규 상장) 차이.
- 주의: U2·U3 보류 기간 값은 개선 워크플로우 전에 연구자(Claude)가 먼저 봤다. 설계 에이전트에게는 알리지 않았다.

## 개선 워크플로우 (에이전트 14개)

5개 트랙(신호 구성 / 유니버스 규칙 / 포트폴리오 구성 / 개별 종목 진입·청산 / 국면·노출) 설계 15개 → 심사위원회가 12개 확정 →
U1·U2·U3에서 기본과 짝 비교 → 통과안 적대적 검증 → 보류 기간 1회. 손익 계산 320회.
주 판정: U3 2021~ · 2022~ 모두 기본 + 0.20 이상, U1·U2 악화 없음, 짝 부트스트랩 p < 0.10, 이웃·수수료 2배 강건.

| 개선안 | U3 2021~ / 2022~ | 결과 |
|---|---|---|
| **숏 스퀴즈 방어** (60일 고점 1σ 안 숏 제외·주중 청산) | **1.41 / 0.75** | **생존 → 채택** |
| 일별 펀딩 중앙값 정렬 | 1.49 / 0.94 | 기준 통과, 검증에서 기각 (위약 대비 우연과 구별 안 됨, U2에서 재현 안 됨) |
| 7일·30일 펀딩 결합 | 1.66 / 1.21 | U1·U2 악화로 탈락 |
| 매일 평가 + 순위 완충 (20%/40%) | 1.75 / 1.33 | U2 1.70 < 1.77로 탈락 |
| 30일 수익률 성분 제거, 상장 180일, 극단 펀딩 제외, 고변동 제외, 베타 중립, 북 변동성 타게팅, 캐리 작은 주 축소, 롱 칼날 방어 | 0.64 ~ 1.02 | 탈락 |

- 검증 발견: 기본 전략의 종목 선택을 무작위로 조금 흔들기만 해도 U3 Sharpe가 평균 +0.13 오른다 (기본이 U3에서 운 나쁜 표본).
  주 단위 블록 부트스트랩은 이 종목 교체 잡음을 재지 못해 위양성률이 약 33%였다.
- 숏 스퀴즈 방어 보류 기간 (하락장): U1 1.33 → **1.92**, U2 2.38 → 2.32, U3 -0.40 → **0.31** (MDD -45% → -28%).
  노출을 같게 맞춘 기본보다도 낫다 (U3 -0.37, U1 1.62). 약점: 개선이 소수 스퀴즈 사건에 몰림(개발 1000PEPE 2024가 26%),
  Holm 보정 p 0.20, DSR(시도 320회) 0.76 — "알파 개선"보다 "비용 없는 스퀴즈 위험 관리"로 본다.

## 모멘텀과 결합 (고정 56개, 순비중, 수수료·펀딩 반영)

| 캐리 비중 | 전체 Sharpe | 연수익 | MDD | 2022 ~ 2025-09 | 보류 |
|---|---|---|---|---|---|
| 0% (모멘텀만) | 1.34 | 28.1% | -23.1% | 0.53 | 1.99 |
| 30% | 1.87 | 31.3% | -16.7% | 0.92 | 2.35 |
| **50% (채택)** | **2.21** | 33.4% | -13.9% | 1.23 | 2.44 |

- 일 수익률 상관: 모멘텀 결합 vs 캐리 기본 -0.06, vs 스퀴즈 방어 0.22 (숏을 현금으로 바꿔 순 롱 +0.04로 기움).
- 연도별 (모멘텀만 → 50%): 2022 -15% → -4%, 2023 +41% → +29%, 2025 +10% → +23%.
- 시계열 모멘텀 단독은 약하다 (Sharpe 0.58, 2022~2025 0.14) — 실거래 결합의 성과는 듀얼 모멘텀과의 분산에서 나온다.
- 권고는 30% 안팎이었다 (U3처럼 캐리가 무너지면 50%의 손해가 큼, U3 기준 보류 50% 결합 0.95). 사용자가 50%로 결정.

## 운용 메모

- 중단 규칙 (사전 등록): 실거래 6개월 Sharpe < 0 또는 MDD < -20%면 캐리 중단 검토, 펀딩 손익 누적이 음수면 재검토.
- 캐리 몫 점검: 텔레그램 보고의 "🎯 목표" 줄 (상쇄 전 전략별 목표 노출).
- 재현: `uv run python -m alpha.backtest.funding_carry [--holdout]` (기본 전략), 비중 함수는 `strategies.carry.carry_weights`,
  실거래 결합은 `strategies.portfolio.live_weights`.
